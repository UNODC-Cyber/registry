# Security policy

## Reporting a vulnerability

Please report security problems **privately** through GitHub's private vulnerability reporting:

1. Open this repository's **Security** tab.
2. Choose **Report a vulnerability** and describe the issue.

Private reports are visible only to the organization owners. Please do **not** open a public issue for a security problem. GitHub private vulnerability reporting is the only reporting route.

## Scope

- The integrity of the published snapshots (manifest, signature, shard digests)
- Any personal data that appears in this repository

## Personal data

This repository is designed to contain no personal data. If you find any, treat it as a security report and use the private route above.
